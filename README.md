# Programming with Python — Written Assignment
**Course:** CSEMDSPWP01 | IU International University of Applied Sciences

A Python program that selects the best-fit ideal functions for noisy training data using least squares, maps test points to those functions, persists everything in SQLite, and visualises the results with Bokeh.

---

## What it does

1. **Loads** three CSV datasets — training data (4 functions × 400 points), 50 ideal functions, and 100 test points.
2. **Selects** the single ideal function per training column that minimises the sum of squared residuals.
3. **Maps** each test point to one of the four chosen ideal functions if the deviation satisfies the √2 threshold criterion.
4. **Saves** all data and results to a SQLite database via SQLAlchemy.
5. **Visualises** training vs ideal fits and test-point assignments as interactive Bokeh HTML plots.

## Algorithm

### Ideal-function selection (Least Squares)
For each training column `y1`–`y4`, compute the SSE against every one of the 50 ideal functions:

```
SSE(f) = Σ (y_train(xᵢ) − f(xᵢ))²
```

The function with the lowest SSE is selected. The margin between best and second-best is typically several orders of magnitude, confirming unambiguous selection.

### Test-point assignment (√2 threshold)
A test point `(x, y)` is assigned to ideal function `f` if:

```
|y − f(x)|  ≤  max_training_deviation(f) × √2
```

where `max_training_deviation(f)` is the largest absolute residual between the training column and `f` across all 400 training rows. When multiple functions satisfy the criterion, the one with the smallest deviation wins.
